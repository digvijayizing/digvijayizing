### 👋 About Me

```yaml
name:            Digvijay Singh Shaktawat
role:            Infrastructure / DevOps Engineer
focus:           Cloud Infra (AWS · GCP · OCI)  →  Kubernetes  →  GPU / HPC clusters
day_to_day:      Terraform, CI/CD, Kubernetes, Slurm-on-Kubernetes (Slinky), GPU cluster validation
currently:       Operating & scaling multi-cloud GPU infrastructure for AI/HPC workloads
fun_fact:        I debug NCCL timeouts for a living and still love a clean terraform plan
```

- 🔧 I build and operate the **infrastructure layer** AI workloads run on — from `terraform apply` to a healthy, scheduler-ready GPU fleet.
- ☁️ Comfortable across **AWS, GCP, and OCI** — provisioning, IaC standardization, and multi-cloud Kubernetes (EKS / GKE / OKE).
- 🧠 Spend a good chunk of my time in **GPU & HPC land**: cluster bring-up, Slurm / Slinky scheduling, GPU health validation (NCCL, DCGM), and production on-call for large-scale training/inference fleets.
- 📈 Big believer in **automation over toil** — if I do something twice, it becomes a script; if I do it thrice, it becomes a pipeline.
- 🌱 Currently deepening my understanding of distributed training internals (parallelism strategies, collective communication) beyond just keeping the infra healthy.
